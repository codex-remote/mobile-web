# Mobile Web 会话与对话术语规范

本文定义 Codex Remote Mobile Web 在产品文案、设计讨论、代码、Runtime API 和问题描述中使用的统一术语。

## 核心术语

| 中文术语 | 英文/模型 | 定义 | 典型使用位置 |
| --- | --- | --- | --- |
| 项目 | `Project` | Mac Agent 提供的一个工作区，是会话的上级容器。 | 项目导航、创建会话、源码访问 |
| 会话 | `Session` | 一个持续存在的工作上下文，包含标题、所属项目、状态和零个或多个对话轮次。 | 左侧会话列表、会话选择、会话详情 |
| 对话 | Conversation | 某个会话中全部轮次组成的完整可见交流内容。它是 UI 和产品概念，不是独立 Runtime 数据实体。 | 对话区域、对话滚动、对话展示 |
| 对话轮次 | `Run` | 用户提交一次指令，到 Codex 完成、失败或取消的一次完整处理过程。 | 创建 Run、取消 Run、轮次状态、历史轮次 |
| 消息 | `ChatMessage` | 对话轮次中展示给用户的用户、助手或系统消息。 | 消息列表、Markdown 回答、系统提示 |
| 执行事件 | `RuntimeEvent` | 轮次内部的流式增量、工具调用、状态变化和终态事件。 | SSE、流式恢复、Runtime 检查器 |
| 工具步骤 | `ToolStep` | 从执行事件整理出的可见工具调用过程。 | 助手回复中的执行轨迹 |

## 层级关系

```text
项目 Project
└── 会话 Session
    └── 对话轮次 Run
        ├── 用户消息 ChatMessage
        ├── 助手消息 ChatMessage
        ├── 工具步骤 ToolStep
        └── 执行事件 RuntimeEvent
```

一个会话可以没有轮次。只有会话详情请求成功并明确返回零个 `Run` 时，才能把它判断为新会话或空会话。

## 示例

```text
会话：优化 Mobile Web 会话加载
├── 第 1 轮：确认异常跳转的原因 -> Codex 返回分析结果
├── 第 2 轮：实施第一期优化 -> Codex 修改并验证代码
└── 第 3 轮：讨论后续阶段 -> Codex 返回第二期建议
```

以上三个轮次共同组成该会话的完整“对话”。每个轮次可以包含多条消息、工具步骤和 Runtime 事件。

## 产品文案规则

推荐使用：

- 左侧导航：`会话列表`
- 用户点击列表项：`打开会话`
- 读取 Session 快照和历史 Run：`正在载入会话`
- 展示全部 Run：`历史轮次` 或 `对话`
- 用户提交一次指令：`开始新轮次`
- 单次处理过程：`当前轮次`
- 无 Run 且详情已成功加载：`新会话` 或 `从这里开始`
- Session 不在目录中：`会话不可用`

避免使用：

- `轮次对话`：层级不清，应根据语义改为“对话轮次”或“对话”。
- `加载对话`：无法说明是在加载 Session、Run 还是单条消息。
- `新对话`：如果实际创建的是 `Session`，应使用“新建会话”。
- `发送会话`：用户发送的是指令或消息，并由此创建一个新轮次。

## 数据与状态规则

- `Session` 是目录选择和持久上下文的唯一实体，不使用“Conversation 对象”作为它的别名。
- `Run` 是一次用户提交对应的执行实体，在中文中统一称为“对话轮次”，简称“轮次”。
- `ChatMessage` 是展示模型，不代替 `Run` 的执行状态。
- `RuntimeEvent` 是流式事实来源，需要通过 Run 快照和持久 cursor 恢复，不能把 SSE 连接本身视为最终状态。
- 会话目录数据只代表 Session 摘要，不代表历史轮次已经加载。
- 不得通过 `messages.length === 0` 判断新会话；必须先确认会话详情处于 `ready`，并且服务端返回零个 Run。
- “会话详情加载”指获取 Session 快照并补齐所包含的 Run；“轮次刷新”指更新某个活跃或变化的 Run。

## 问题描述模板

推荐按以下格式描述问题：

```text
用户在会话 A 的第 3 个轮次中查看回答时，点击会话 B。
会话 B 的详情和历史轮次尚未加载完成，页面错误显示为空会话。
预期应显示会话加载状态，成功确认零个 Run 后才能显示新会话状态。
```

这种表达能够明确区分会话选择、详情加载、轮次数据和消息展示，避免把不同层级的问题混在“对话加载失败”一句话中。
